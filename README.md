# Plugin Style Advisor (플러그인 스타일 어드바이저)

문서 작성과 업무 실행을 **코딩처럼 체계화**할 수 있도록 돕는 기획안입니다.

## 1) 문제 정의
- 문서/업무는 반복되지만, 개인마다 방식이 달라 품질 편차가 큼
- 템플릿이 있어도 상황별로 맞지 않아 실제 활용률이 낮음
- 최신 생산성 도구/AI 기능을 쓰고 싶어도 무엇을 언제 써야 할지 판단이 어려움

## 2) 제품 비전
사용자가 업무 목표를 입력하면 아래를 자동화하는 “워크플로 코파일럿”:
1. 업무 유형 분석
2. 실행 플랜 생성(단계/마일스톤/체크리스트)
3. 최적 템플릿 추천 (없으면 자동 생성)
4. 업무 스타일 기반 스킬/플러그인 추천
5. 결과물 완성까지 가이드 + 품질 점검

## 3) 핵심 사용자 시나리오
### A. 신규 프로젝트 기획서
- 입력: "3개월 안에 신규 서비스 기획서 완성"
- 출력:
  - 주차별 로드맵
  - 기획서 템플릿 (시장/문제/솔루션/ROI)
  - 발표자료 생성용 스킬 추천
  - 누락 항목 자동 점검

### B. 운영 업무 표준화
- 입력: "고객 VOC 주간 보고 체계 만들기"
- 출력:
  - 반복 가능한 SOP 플랜
  - VOC 분류 템플릿
  - 자동 요약/리스크 알림 스킬

## 4) 기능 구조
## 4.1 Plan Engine
- 목표를 WBS(Work Breakdown Structure)로 분해
- 단계별 산출물/완료조건/의존성 정의
- 일정·난이도·리스크 기반 우선순위 조정

## 4.2 Template Selector & Builder
- 저장소에서 템플릿 검색 (업무 유형/산업/문서 길이)
- 적합도 점수로 후보 추천
- 템플릿이 없으면 AI가 신규 생성
- 생성 후 버전 관리(초안→검토→확정)

## 4.3 Skill Recommendation Engine
- 사용자 업무 스타일 분석:
  - 빠른 실행형, 완성도 중심형, 협업 중심형 등
- 스타일 + 업무 유형 매칭으로 스킬 추천:
  - 아이데이션, 리서치, 정리, 시각화, 검토
- 추천 이유/기대효과/주의점 제시

## 4.4 Execution Copilot
- 각 단계에서 바로 실행 가능한 액션 버튼 제공
- 진행률 추적(완료율, 지연 요인)
- 자동 리마인드 + 다음 단계 제안

## 4.5 Quality Gate
- 문서 품질 체크리스트 자동 평가
- 논리/구조/근거/가독성 점수화
- 부족한 섹션 개선안 제안

## 5) 기술 트렌드 반영(최신 지향)
- LLM 기반 오케스트레이션 + 도구 호출
- RAG(사내 지식/기존 문서 재활용)
- 멀티 에이전트(플래너/작성/검토 역할 분리)
- 이벤트 기반 워크플로(상태 전이 추적)
- 플러그인 마켓 방식(업무별 기능 확장)

## 6) 플러그인 스타일 어드바이저 설계
### 6.1 플러그인 메타데이터 예시
- name: 플러그인 이름
- category: planning | writing | analysis | review
- use_case: 어떤 업무에서 효과적인지
- input_schema: 필요한 입력 항목
- output_schema: 생성 결과 구조
- quality_signal: 성공 측정 지표

### 6.2 추천 로직(간단 버전)
1. 업무 목적 분류 (예: 보고서, 기획, 운영)
2. 사용자 스타일 스코어링
3. 현재 진행 단계 인식
4. 단계별 후보 플러그인 랭킹
5. 상위 3개 추천 + 근거 설명

## 7) MVP 범위 (6~8주)
- 목표 입력 → 플랜 자동 생성
- 템플릿 검색/추천
- 템플릿 미존재 시 자동 생성
- 스킬 추천 1차 버전(룰 기반)
- 결과물 품질 체크 1차 버전

## 8) 확장 로드맵
- V2: 팀 협업 기능(역할 분담, 승인 흐름)
- V3: 개인화 추천(사용자 히스토리 학습)
- V4: 성과 대시보드(시간 절감/품질 향상 지표)

## 9) 성공 지표 (KPI)
- 문서 완성 시간 30% 단축
- 템플릿 재사용률 50% 이상
- 최초 제출 통과율 20% 향상
- 사용자 주간 활성률(WAU) 증가

## 10) 바로 실행 가능한 초기 템플릿
### [템플릿] 업무 자동화 기획 1페이지
1. 목표(왜 하는가)
2. 현재 문제(현황/병목)
3. 원하는 결과(정량지표)
4. 실행 단계(주차별)
5. 필요한 스킬/도구
6. 리스크/대응
7. 완료 기준
